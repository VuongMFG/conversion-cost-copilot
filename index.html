Conversion Cost Analysis Knowledge Base

This knowledge base contains conversion cost data used for cost analysis. The dataset provides cost information by organizational team, cost category, MS type, account and monthly amount.

The detailed dataset is available in:

conversion_cost.csv

Dataset Structure

Column Description
Team check The organizational team or business group responsible for the cost.
Category The high-level cost category. Examples include Labor, Material, Overhead or other cost groups.
MS type The detailed classification of cost type within each category.
Account name The detailed account or cost item name.
Year The fiscal year of the cost data.
Jan - Dec Monthly cost amount for each month. The value represents the cost amount recorded for that month.

How to Query This Dataset

Users can ask questions by combining these dimensions:

  • Team
  • Category
  • MS type
  • Account name
  • Year
  • Month

Example questions:

  • What is the cost amount of EA/GA Labor category in January 2026?
  • Show the monthly cost trend of Labor Cost Welfare.
  • Compare cost between different teams.
  • What is the total cost for a specific account in 2026?

Data Interpretation Rules

  • Each row represents one cost account record.
  • Monthly columns represent the cost amount for that month.
  • To find a specific value, filter by Team, Category, MS type, Account name and Year.
  • The combination of Account name + Year + Month identifies a specific cost value.
